# Variables
A variable is a name given to a memory location in python that stores data. 

Naming rules for variables; 
1. It must start with a letter (a-z, A-Z) or an underscore ( _ )
2. It can only contain alphanumerical characters (A-Z, 0-9)
3. Variables are case sensitive (age, Age and AGE), all three are different.
4. Cannot name variables after reserved words. (if, else, for, while)

# Data Types
A data type classifies the kind of data a variable can hold. 

Common data types;
1. Integers - Whole numbers.
2. Floating point numbers - NUmbers with a decimal point. 
3. Strings - A sequence of characters enclosed between '' single or "" double quotes. 
4. Booleans - Represents truth values; True or False. 
5. List - An ordered changable collection of items enclosed within a square bracket [].
6. Tuples - An ordered, unchangable collection of items enclosed within a paranthesis ().
7. Dictionaries(dict) - An unordered collection of key-value pairs enclosed within curly brackets {}.



# Operators
A symbol that perfoms operations on variables and values
Common Operators;
1. Arithmetic - +,-,*,%
2. Assignment: =, +=, -=, *=


# Comparison Operators
Comparison operators are used to compare two values and return a boolean result
They include
1. == Equal to
2. != Not Equal to\
3. > Greater than 
4. < Less than
5. >= Greater than or equal to 
6. <= Less than or Equal to 

# Inputs and Outputs
Input : The input() function is used to get data from the user, it will always return the input as a string
Output: The print() function used to display the text or variable values on the console.
